# Fortunato Link per Mac M1

App nativa macOS Apple Silicon per collegarsi all'app Android Fortunato Link sulla stessa rete Wi-Fi.

## Installazione
1. Estrai il file ZIP.
2. Trascina **Fortunato Link.app** in Applicazioni.
3. Al primo avvio usa clic destro > Apri. La build di prova è firmata localmente, non notarizzata da Apple.
4. Avvia la condivisione sull'Android, quindi inserisci nel Mac indirizzo e codice mostrati dal telefono.

Richiede macOS 11 o successivo e l'app Android Fortunato Link.
